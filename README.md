SEO & Social Media Automation Pro هي أداة كاملة ومتطورة تجمع بين قوة الذكاء الاصطناعي (Groq AI) وأدوات SEO المتقدمة وإدارة وسائل التواصل الاجتماعي في منصة واحدة سهلة الاستخدام.

## 💻 التثبيت

### المتطلبات الأساسية

- Python 3.8 أو أحدث
- pip (مدير حزم Python)
- Groq API Key (مجاني من [console.groq.com](https://console.groq.com))

### خطوات التثبيت

#### 1. استنساخ أو تحميل الملفات

```bash
# إنشاء مجلد المشروع
mkdir seo-automation-pro
cd seo-automation-pro

# نسخ الملفات
# seo_social_automation_complete.py
# requirements_updated.txt
```

#### 2. تثبيت المكتبات المطلوبة

```bash
pip install -r requirements_updated.txt
```

أو تثبيت يدوي:

```bash
pip install streamlit requests beautifulsoup4 pandas lxml groq
```

#### 3. الحصول على Groq API Key

1. اذهب إلى [console.groq.com](https://console.groq.com)
2. سجل حساب مجاني
3. انتقل إلى API Keys
4. أنشئ مفتاح API جديد
5. انسخ المفتاح (ستحتاجه لاحقاً)

#### 4. تشغيل التطبيق

```bash
streamlit run seo_social_automation_complete.py
```

سيفتح التطبيق تلقائياً في المتصفح على:
```
http://localhost:8501
```

## ⚙️ الإعدادات المتقدمة

### تخصيص Groq AI

يمكنك تغيير إعدادات AI:

```python
# في الكود
def generate_ai_content(prompt, max_tokens=2000, temperature=0.7, model="llama-3.3-70b-versatile"):
```

**المتغيرات:**
- `max_tokens`: عدد الكلمات (افتراضي: 2000)
- `temperature`: الإبداع 0.1-2.0 (افتراضي: 0.7)
- `model`: النموذج (افتراضي: llama-3.3-70b-versatile)

**النماذج المتاحة:**
- `llama-3.3-70b-versatile` - الأفضل للمحتوى العام
- `llama-3.1-70b-versatile` - بديل قوي
- `mixtral-8x7b-32768` - سريع وفعّال

## 🔧 استكشاف الأخطاء

### المشكلة: "Groq API غير متصل"

**الحل:**
1. تأكد من تثبيت المكتبة: `pip install groq`
2. تحقق من API Key
3. اختبر الاتصال على console.groq.com

### المشكلة: "خطأ في تحليل الموقع"

**الحل:**
1. تأكد من صحة الرابط (يجب أن يبدأ بـ http:// أو https://)
2. تحقق من اتصال الإنترنت
3. بعض المواقع قد تمنع السكريبتات - هذا طبيعي

### المشكلة: "التطبيق بطيء"

**الحل:**
1. قلل عدد الكلمات في توليد المحتوى
2. استخدم نموذج أسرع في Groq
3. قلل عدد الباكلينكس في كل حملة
