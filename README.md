# SEO Automation Tool 🚀

أداة أتمتة SEO احترافية مبنية بـ Streamlit - بديل مجاني لـ MoneyRObot

## الميزات الرئيسية 📋

### 1. 🔗 Backlink Builder (بناء الروابط الخلفية)
- بناء روابط خلفية تلقائياً من مصادر متعددة
- دعم أكثر من 150 منصة
- تتبع حالة كل رابط
- تصدير النتائج إلى CSV

### 2. ✍️ Content Generator (مولد المحتوى)
- توليد محتوى محسن لمحركات البحث
- دعم أنواع محتوى متعددة (مقالات، أوصاف منتجات، Meta descriptions)
- اختيار نمط الكتابة (احترافي، ودي، تقني، إلخ)
- تحديد عدد الكلمات المطلوبة

### 3. 🔍 Keyword Research (البحث عن الكلمات المفتاحية)
- اكتشاف كلمات مفتاحية جديدة
- تحليل حجم البحث والمنافسة
- معلومات عن CPC وصعوبة الترتيب
- رسوم بيانية تفاعلية

### 4. 🔄 Article Spinner (إعادة صياغة المقالات)
- إعادة صياغة النصوص بمستويات مختلفة
- الحفاظ على كلمات مفتاحية محددة
- مقارنة النص الأصلي بالمعاد صياغته
- تقرير عن نسبة التشابه

### 5. 📊 Site Analyzer (محلل المواقع)
- تحليل SEO شامل
- فحص الروابط والصور
- استخراج الكلمات المفتاحية
- تقييم عام بالنقاط

### 6. 📈 Rank Tracker (متتبع الترتيب)
- تتبع ترتيب موقعك في محركات البحث
- مقارنة مع الترتيب السابق
- دعم محركات بحث متعددة
- تقارير مفصلة

## التثبيت 💻

### المتطلبات الأساسية
- Python 3.8 أو أحدث
- pip

### خطوات التثبيت

1. **استنساخ أو تحميل الملفات**
```bash
# إنشاء مجلد المشروع
mkdir seo-automation-tool
cd seo-automation-tool
```

2. **تثبيت المكتبات المطلوبة**
```bash
pip install -r requirements.txt
```

3. **تشغيل التطبيق**
```bash
streamlit run seo_automation_tool.py
```

4. **فتح المتصفح**
سيفتح التطبيق تلقائياً في المتصفح على العنوان:
```
http://localhost:8501
```

## الاستخدام 📖

### Backlink Builder
1. أدخل رابط موقعك المستهدف
2. حدد Anchor Text
3. اكتب المحتوى المراد نشره
4. حدد عدد الباكلينكس
5. انقر على "بدء بناء الباكلينكس"

### Content Generator
1. اختر نوع المحتوى
2. أدخل الكلمات المفتاحية
3. حدد نمط الكتابة وعدد الكلمات
4. أدخل الموضوع
5. انقر على "توليد المحتوى"

### Keyword Research
1. أدخل الكلمة المفتاحية الأساسية
2. اختر اللغة والدولة
3. حدد حجم البحث المطلوب
4. انقر على "بحث عن الكلمات المفتاحية"

### Article Spinner
1. الصق النص المراد إعادة صياغته
2. حدد مستوى إعادة الصياغة
3. اختر الكلمات التي تريد الاحتفاظ بها
4. انقر على "إعادة الصياغة"

### Site Analyzer
1. أدخل رابط الموقع
2. اختر أنواع التحليل المطلوبة
3. انقر على "تحليل الموقع"

### Rank Tracker
1. أدخل موقعك
2. اختر محرك البحث والموقع الجغرافي
3. أدخل الكلمات المفتاحية (واحد في كل سطر)
4. انقر على "تتبع الترتيب"
